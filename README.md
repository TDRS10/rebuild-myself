# راجع لنفسي — REBUILD MYSELF

موقع عربي (RTL) كامل لاستعادة التوازن النفسي والمالي والعملي بعد الضغط العاطفي والإرهاق المالي.
**أنا أستحق أبدأ من جديد.**

كل البيانات محفوظة **محليًا فقط** في LocalStorage على جهازك — لا خادم، لا حسابات، لا إعلانات.

## التشغيل

```powershell
# أي خادم ثابت يكفي، مثال:
python -m http.server 8811
# ثم افتح: http://localhost:8811
```

للتثبيت على أندرويد: افتح الموقع في Chrome ← قائمة (⋮) ← «إضافة إلى الشاشة الرئيسية».
يعمل دون إنترنت بعد أول فتح (Service Worker).

## الاختبارات

```powershell
node tests/test-store.js   # 15 مجموعة: الحسابات والتقسيم والمحاكاة والتحديات والحفظ
node tests/smoke.js        # عرض الصفحات التسع وحفظ البيانات بعد إعادة التحميل
```

## الصفحات

| الصفحة | الأقسام |
|---|---|
| الرئيسية | الحالة النفسية اليوم، الرصيد المتاح، إجمالي التحويش، أيام الالتزام بالشغل والخطة، نسبة الأهداف، رسالة تحفيزية، زر «ابدأ يومك» |
| استعادة نفسي | مزاج وطاقة (1–10)، جودة النوم، نزلت الشغل؟، نشاط مفيد؟، صرف بسبب التوتر؟، مذكرات، أزعجني/أسعدني، إنجازات صغيرة، مهام «أنا مش مطالب أصلح كل حاجة النهارده» |
| أموالي | دخل (تقسيم تلقائي 40/35/15/10 قابل للتعديل)، مصاريف مصنفة (أكل، مواصلات، خروجات، أقساط، هدايا)، محفظة تحويش منفصلة لا تُحتسب رصيدًا، تنبيه المصروف الكبير وميزانية الخروجات، سجل كامل، رسم بياني «أين تذهب أموالي» |
| شغلي (Talabat) | طلبات × سعر الطلب + بونص + إكراميات − مصاريف = الصافي، الساعات، أهداف تدريجية 2/4/6، مقارنة أسبوع/أسبوع |
| حدودي | تسجيل مواقف الضغط (3 أسئلة نعم/لا)، حدود المصروف والهدايا، تذكير «الحب لا يعني الاستدانة»، أفكار خاصة لا تُرسل |
| أهدافي | ديون، طوارئ، موتوسيكل، إنجليزية، مهارات، دراسة، مشروع — مبلغ مستهدف/محفوظ/نسبة/موعد |
| التحديات | 6 تحديات (7 أيام و30 يومًا) — بدء/إيقاف/إعادة بلا عقاب |
| التقارير | أسبوعي/شهري، متوسط المزاج، محاكي تحويش متحفظ/متوسط/متفائل بناءً على أرقامك الفعلية |
| الإعدادات | النسب، الميزانية، PIN اختياري، تنبيهات، تثبيت PWA، تصدير/استيراد JSON، مسح البيانات |

## ملاحظات

- PIN حماية للعرض على الجهاز المشترك، ليست تشفيرًا كاملًا.
- التنبيهات اليومية (Notification) تُرسل عند فتح التطبيق فقط — لا خلفية دون خادم.
- لا توجد بيانات تجريبية؛ الحالة تبدأ فارغة.
- خلفية «المطر الرقمي» الحية (DataRain) يمكن قفلها أو تفعيلها من الإعدادات ← «🎨 المظهر».
